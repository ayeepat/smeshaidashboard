# СМЭШ AI — панель аналитики

Внутренняя админ-панель для СМЭШ AI (расширение-помощник по МЭШ). Статический
сайт без сборки: `index.html` + `styles.css` + `app.js`, размещён на GitHub Pages.

**Живой адрес:** https://ayeepat.github.io/smeshaidashboard/

## Что показывает

- **Обзор** — выручка, расход на ИИ (кредиты API), «чистыми», средний чек, DAU/WAU/MAU,
  всего устройств, решения/тесты/ГДЗ, расход на пользователя за день/неделю/месяц;
  графики выручки vs расхода, активных устройств, использования функций,
  разбивка по браузерам и лицензиям.
- **Пользователи** — каждое устройство с расширением. По умолчанию отсортировано
  по **расходу на мои API-кредиты**. Фильтры: браузер (Chrome / Yandex / …),
  лицензия, поиск, сортировка, пагинация. Клик по строке — карточка устройства
  с историей, предметами и событиями.
- **Деньги** — покупки, валовая и чистая выручка (за вычетом возвратов), средний
  чек, подписки/навсегда, шлюзы, реферальная программа.
- **Предметы** — самые популярные предметы по обращениям, устройствам и расходу.
- **Удержание** — возврат на 1/7/30 день и недельные когорты.
- **Бот и отзывы** — напоминания о продлении, опрос ушедших («почему»),
  обращения и идеи из телеграм-бота, привязки Telegram.
- **Ошибки** — последние клиентские ошибки (без данных пользователя).

Период везде переключается: **день / неделя / месяц / всё** (московское время).

## Каким числам можно верить

Панель специально разделяет два вида данных, и это видно в баннере на «Обзоре»:

- **Полные, по всем:** выручка, возвраты, покупки, рефералы, бот и отзывы. Их
  пишет сервер на каждое событие, независимо от настроек пользователя.
- **Выборка:** устройства, браузеры, DAU/WAU/MAU, решения/тесты/ГДЗ, предметы,
  удержание, ошибки, серверные вызовы 302.AI. Телеметрия в расширении
  **выключена по умолчанию** (`telemetryEnabled = false`), и VPS-прокси тоже
  ничего не шлёт без явного согласия. Цифры настоящие, но это нижняя граница —
  установок и решений всегда больше, чем видит панель.

Возвраты считаются по дате возврата денег, поэтому возврат старой покупки
попадает в текущий период — это обычная бухгалтерская логика, а не ошибка.
«Отозвано ключей» — не то же самое, что возврат: ключ можно отозвать за
злоупотребление, не возвращая деньги.

## Как это работает

Данные приходят из воркера лицензий (`smesh-licenses` на Cloudflare) через
эндпоинты `GET /admin/stats/*`, защищённые заголовком `x-stats-token`
(секрет `STATS_SECRET` на воркере). Это **отдельный ключ только для чтения** —
не `ADMIN_SECRET`. Воркер отклоняет любой запрос с заголовком `Origin` на
маршрутах выдачи/отзыва лицензий, а preflight для статистики разрешает ровно
`Content-Type, X-Stats-Token`. Поэтому браузер с админ-ключом не получал 401,
а падал с «Failed to fetch»: запрос блокировался до отправки.

Расширение шлёт **обезличенную** телеметрию на `POST /t` — только типы событий,
предметы, счётчики токенов и стоимость, без текста заданий и ответов.

При первом входе введите ключ статистики — он хранится в `localStorage` этого
браузера.

Пересборка таблицы покупок из KV — операция с админ-правами, из браузера она
недоступна by design. С машины, где лежит `ADMIN_SECRET`:

```bash
curl -X POST https://smeshapi.site/admin/backfill-licenses -H "x-admin-token: $ADMIN_SECRET"
```

## Локальный запуск

```bash
python3 -m http.server 4599
# открыть http://localhost:4599
```

Адрес бэкенда меняется в `API_BASE` в начале `app.js`; курс $→₽ живой —
официальный курс ЦБ РФ, который отдаёт воркер (`/admin/stats/rate`), кэш 12ч.
